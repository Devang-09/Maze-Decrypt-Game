Maze Decrypt Game

Collect all tokens in the maze. Each token gives a small hint. After collecting them, you'll receive an encrypted fictional session id. Use the hints to decrypt it and enter the password to win.

Move: arrows / WASD

Hints system

Each token contains one-digit hint. The fictional code was encrypted with a Caesar cipher whose shift equals the sum of digits shown in collected tokens. Game only — not for real passwords.

Example: if tokens show 2 + 3 + 1 = shift 6, and encrypted text is "nkx", real secret after shifting back by 6 is "here".
Options & Variations
  • Change token count or maze size for difficulty.
  • Modify the code or change to another symmetric cipher in the code for variety.
Note: This is a safe puzzle game. Do not use this to attempt to access or bypass real systems.
