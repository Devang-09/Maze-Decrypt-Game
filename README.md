# Maze Decrypt Game

**Maze Decrypt Game** is a web-based puzzle where players navigate procedurally generated mazes, collect tokens with hint digits, and decrypt a fictional session ID using a Caesar cipher.

### To play click on ➡️ [Maze-Decrypt-Game](https://devang-09.github.io/Maze-Decrypt-Game/)
---

## Features (Current)

- Procedurally generated mazes of different sizes (11×11, 21×21, 31×31)
- Collect tokens to reveal digits that determine Caesar cipher shift
- Dynamic and responsive canvas
- Interactive controls: move player, reset, regenerate maze, adjust size and token count
- Safe puzzle game — purely educational/fun

## How to Play

1. Use **Arrow keys** or **WASD** to move the player.
2. Collect all tokens in the maze. Each token shows a digit hint.
3. After collecting all tokens, the encrypted session ID appears.
4. Use the sum of collected digits as the Caesar cipher shift to decrypt the session ID.
5. Enter the decrypted session ID to win.

---

## Controls

- **Size:** Select maze size
- **Tokens:** Set number of tokens
- **Generate Maze:** Creates a new maze
- **Reset Player:** Reset position and tokens
- **Movement:** Arrow keys / WASD
